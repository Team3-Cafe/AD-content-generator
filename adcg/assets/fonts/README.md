# Bundled font

`NotoSansKR.ttf` is the variable-weight Noto Sans KR font from the official
Google Fonts repository. It is stored under a stable filename so the layout
renderer can use the same Korean-capable font on local machines and VMs.

- Source: https://github.com/google/fonts/tree/main/ofl/notosanskr
- Upstream file: `NotoSansKR[wght].ttf`
- License: SIL Open Font License 1.1 (`OFL.txt`)
