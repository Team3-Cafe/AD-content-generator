# AD-content-generator

생성형 AI를 활용하여 소상공인이 상품 이미지, 광고 문구, 배너 이미지 등 광고 콘텐츠를 쉽게 제작할 수 있도록 돕는 서비스입니다.

## Team Roles

- PM:
- Scrum Master:
- AI Engineer A - Data: 
- AI Engineer B - Model/Experiment:
- AI Engineer C - Evaluation/API/Demo:

## Core Features

- 상품/서비스 정보 기반 광고 문구 생성
- 상품 이미지 기반 광고 콘텐츠 생성
- 생성 결과 비교 및 선택 기능

## Tech Stack

- Python
- FastAPI or Streamlit/Gradio
- OpenAI API
- GCP VM with L4 GPU
- `skia-python` is required for prompt layout rendering
